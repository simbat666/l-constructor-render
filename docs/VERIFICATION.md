# Проверка локального MVP — 2026-09-10

## Дополнение: два вида схем и рамки

- Изучены актуальные `DxfAssemblyExporter.cs` и `dxf-tools/assemble_dxf.py` в ВЕРСА.
- Sheet 1.1 и Sheet 1.2 из `Схемы.zip` конвертированы отдельно офлайн, аудит исходных DWG
  и полученных DXF прошёл. Хеши и отчёт: `data/dxf-frames/conversion-manifest.json`.
- `npm test`: 6 тестов; `npm run test:cad`: 5 тестов. Всего 11, успешно.
  Восемь одинаковых двигателей дают 2 листа принципиалки и 4 листа внешних соединений.
  Проверено отсутствие чужого вида фрагментов в каждом документе и наличие рамок на страницах.
- Typecheck, production build и diff-check прошли.
- Через `/api/cad/generate` получены два отдельных DXF и ZIP с manifest.
  В браузере три ссылки независимо вызвали события download.
- Визуально проверены две схемы для двух двигателей. Принципиальные фрагменты сохраняют
  высотную привязку к шинам. Для внешних соединений введён сдвиг на 10 мм вверх относительно
  исходных координат, чтобы клеммная строка оказалась внутри зоны «ШКАФ».
- Исходные шаблоны не переписывались. В процессе сборки внешней рамки исключены только
  20 HATCH, лежащих целиком за её правой границей A3.

Ограничения прежние: карты соединений и уникальной маркировки ещё не реализованы,
AutoCAD-открытие этой новой версии не проверено. Это два согласованно выбранных комплекта
черновой компоновки, а не завершённая электрическая КД.

## Предыдущая проверка до разделения документов

## Выполнено

- `npm test`: 6 тестов, успешно. Независимые одинаковые моторы, количество дополнительных
  датчиков, удаление скрытых ответов, блокировка неполного шкафа, ввод, аналоговые I/O.
- `npm run test:cad`: 3 теста, успешно. Повторные шаблоны, недопустимые запросы,
  повторное чтение DXF, аудит и единицы mm. Есть предупреждение pyparsing об устаревшем API
  зависимости; ошибок тестов нет.
- `npm run typecheck`: успешно.
- `npm run build`: успешно. Vinext выводит предупреждение о статической классификации `/`,
  но production-сервер обслуживает страницу и API.
- `git diff --check`: успешно.
- `/api/cad/healthz`: HTTP 200.
- Генерация четырёх фрагментов для двух одинаковых двигателей через same-origin API: HTTP 200.
- GET и HEAD скачивания: HTTP 200, `application/dxf`, `Content-Disposition: attachment`.
  Скачанный файл побайтно совпал с серверным.
- Повторяющийся id экземпляра: HTTP 422. Повтор кода с разными id разрешён.
- Manifest JSON скачивается и сохраняет все четыре экземпляра.
- DXF-превью визуально просмотрено: два двигателя и четыре метки DRAFT присутствуют.
- В браузере пройден опросник прямого пуска 230 В, выбран насос, выполнены генерация и
  скачивание файла блока. Затем выполнены генерация и скачивание шкафа; браузер подтвердил
  события download для обоих действий.

## Что это НЕ подтверждает

Не выполнен полный инженерный аудит всех веток ОЛ и всех CAD-шаблонов.
Не подтверждены подбор физического PLC, полный BOM для ЧП, корректность всех фиксированных
надписей шаблонов, автоматическая маркировка и соединение схем.

Попытка подключиться к AutoCAD 2027 завершилась тайм-аутом. Поэтому открытие нового экспорта
в AutoCAD не подтверждено; проверка ezdxf не заменяет это испытание.
Нагрузочное и многопользовательское тестирование не проводились.
